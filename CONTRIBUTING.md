# Contributing

Thanks for helping improve `package-wizard`.

## Local setup

```bash
npm install
npm test
npm run build
```

## Development rules

- Use Node.js 22 or newer (preferably the version specified in the .nvmrc file).
- Keep changes focused and add tests for behavioral fixes.
- Use Conventional Commits for all commits.
- Prefer small pull requests with clear descriptions.

## Commit format

```text
feat: add dependency update policy
fix: handle missing package metadata
docs: clarify interactive menu usage
```

## Pull requests

- Target the `main` branch.
- Ensure the CI checks pass.
- Include a brief summary of the change and why it matters.
- Mention any relevant issue numbers when applicable.
