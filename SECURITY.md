# Security Policy

## Supported versions

The project currently supports Node.js 22+ and the latest published release on npm.

## Reporting a vulnerability

Please do not open a public GitHub issue for security vulnerabilities.

Send a private report to the maintainer via GitHub Security Advisories or by contacting the Ryan directly through the GitHub profile associated with the project.

Provide:

- a description of the issue
- affected versions or commit ranges
- reproduction steps if available
- any suggested fix or mitigation

We will acknowledge receipt and coordinate a fix and release in a timely manner.
